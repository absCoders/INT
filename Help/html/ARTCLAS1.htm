  1. Tables and Nested Tables

TX Text Control enables you to include tables in your documents. Text in a table can contain virtually any kind of formatting that normal text can: multiple paragraphs with different fonts, indents and line spacing. Even images and, merge fields can be inserted. Frames and shading can be separately adjusted for each individual table cell. Making the table frames invisible allows text to be set in columns.

  1. Text Frames

Freely placeable and programmable text frames can be inserted and positioned as a character or geometrically relative to a paragraph or a page.

Sample:

Right-aligned blue text frame.

The text can flow around an inserted text frame. The distance between the text and the text frame can be specified and the text frame can be aligned.

  1. MS Word Compatible Merge Fields

Using text fields allows developers to build applications, such as mail merge, in which text is retrieved from a

 

database. Additionally, all values of the standard form fields can be imported and manipulated.

 

  1. Dialog boxes

Integrated dialog boxes, for setting paragraph, text and table formatting, page setup, bullets and numbered lists, as well as for searching and replacing are an integrated component of TX Text Control. All dialog box settings are also available as properties.

 

 

 

 

  1. Hyperlinks and Targets

TX Text Control supports document targets, bookmarks and hyperlinks that are 100% compatible to MS Word. You can insert a document link that points to another target. On clicking on the link, TX Text Control jumps to the specified position automatically.

  1. File Formats

Load and save Text (ANSI and Unicode), DOCX, RTF, DOC, HTML and XML. RTF and HTML clipboard formats supported. Export documents to fully featured PDF and PDF/A. Extract text from Adobe PDF documents.

 

  1. Images

Images and can be inserted as a character within a line of text, or as a fixed-positioned object anchored to a paragraph. Filters for TIFF, GIF, BMP, WMF, JPEG and PNG are included. TX Text Control is especially powerful for positioning images in a text. They can be positioned as characters within a line of text, or at a given position on a page. The flow of text around an image or object is controlled via a dialog box. Images can be re-scaled.

  1. Headers and Footers

Programmable headers and footers for each section, with automatic page numbering and import / export as RTF, DOC and DOCX. You can insert all elements into a header or footer like in the main text. Additionally, a first page header or footer can be defined for each page section of the document.

  1. Paragraph Formatting

Paragraph indents left, right, top, bottom, and first line are available, as well as four types of tab, paragraph frames, alignment left, right, centered and justified. Line spacing in inch or %.
